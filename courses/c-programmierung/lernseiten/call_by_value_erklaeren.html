Warum bleibt meine Variable unverändert?

Ein Parameter ist eine eigene Variable. Beim Aufruf wird der Wert des Arguments hineinkopiert. Was die Funktion mit dieser Kopie macht, betrifft nur die Kopie.

Drei Fragen – jede zielt auf denselben Punkt: Was passiert mit dem Wert, was nur mit der Kopie?

Warum bleibt zahl nach dem Aufruf unverändert?

Wo steht der Wert 14, nachdem x = x * 2; ausgeführt wurde?

Das Programm ruft verdopple(zahl) zweimal hintereinander auf. Was gibt printf danach aus?

Merksatz

Parameter sind lokale Variablen. Beim Aufruf wird der Wert des Arguments in den Parameter kopiert. Was die Funktion mit dieser Kopie macht, bleibt im Aufrufrahmen – die Variable in main merkt davon nichts.

Ausblick. Soll eine Funktion den Wert der aufrufenden Variablen wirklich ändern, braucht sie die Adresse: void verdopple(int *x) { *x = *x * 2; } und den Aufruf verdopple(&zahl);. Das ist der nächste Skill „Zeiger als Parameter verwenden“.
